Time Entry settings

1. Microsoft account

Use your company's Entra app registration. The README explains how to create one.

2. Excel file

Paste the sharing link of the time file (Excel: Share → Copy link), click Connect, then pick your sheet. The extension fills in today's row: date, arrival, lunch, back from lunch, and leaving.

4. Teams messages (optional)

The extension posts the message itself, as you, into a Teams chat you choose. No workflow or webhook needed. The first time, Microsoft asks you to allow chat access.

One message per line; a random one is picked each time. You can also paste a Power Automate createArray('…', '…') expression or a JSON array, and it's split into lines automatically. Your first name goes in front, unless the line contains {name} somewhere else. {time} = current time. Leave an event empty to send no message for it.
